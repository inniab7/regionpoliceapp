> 모든 사례는 **2026년 10월**(1일~31일) 한 달 결과다. 계산 규칙 번호는 PRD 5장 ①의 규칙 1~17.
> 자동 시험: [lib/overtime/cases.test.ts](../lib/overtime/cases.test.ts) — 이 표의 "정답"과 앱 계산을 비교한다.
> **검토 방법**: 각 사례의 정답을 현장 기준으로 손계산해 보고, 다르면 "Yuni 정답" 칸에 적어 주세요.
> **2026-10-13 전체 다시 계산**: 기본 초과를 "주 40시간"이 아니라 **"그 달 근무시간 − 월 기준시간"**으로 바꾸고(규칙 4), 야간은 기본 초과에서 빼지 않고 따로 세며(규칙 5·7), 결과에서 합계 줄을 뺐다. 이 문서의 정답은 모두 새 규칙으로 손계산한 값이다.

## 계산 방법 (공통)

```
그 달 근무시간 = (식사 공제 후 근무한 시간 전부) − (휴일로 인정되는 시간) + (휴가 하루 × 8시간)
월 기준시간   = 그 달 평일(월~금) 중 공휴일이 아닌 날 수 × 8시간
기본 초과     = 그 달 근무시간 − 월 기준시간   (0보다 클 때만)
야간          = 22:00~06:00에 일한 시간 전체 (기본 초과와 겹쳐서 센다. 단, 휴일 인정 시간 안의 야간은 휴일에만)
휴일          = 토·일·공휴일에 시작한 근무, 하루 8시간까지 (휴일수당으로 대체되어 위 계산에서 빠짐)
```

## 예시 (규칙 4 설명용): 일반 근무 180시간 + 휴일근무 3일

- 월 기준 160시간. 일반 근무(휴일 제외) 180시간 → **기본 초과 20시간**
- 휴일근무 3일(하루 8시간씩 24시간)은 휴일수당으로 대체 → **휴일 24시간 (3일)**, 위 180시간·기준 계산에는 들어가지 않는다
- 이 예시는 자동 시험(allocate.test.ts)에도 들어 있다.

## 사례 1. 패턴 2 (주간 → 야간 → 비번 → 휴무), 변경 없음

- 등록: 지구대·파출소, 패턴 2, 시작일 10/1(주간), 주간 09~18시, 야간 18~09시
- 근무: 주간 1·5·9·13·17·21·25·29일(8번) / 야간 2·6·10·14·18·22·26·30일(8번)
- **근무 전체**: 주간 8번 × 8 = 64 + 야간 8번 × 14 = 112 → **176시간**
- **휴일 인정**: 5(대체공휴일) 주간 8 + 9(한글날) 주간 8 + 10(토) 야간 앞 8시간 + 17(토) 주간 8 + 18(일) 야간 앞 8시간 + 25(일) 주간 8 = **48시간 (6일)**
  - 10·18일 야간은 18~21시·22~03시 8시간이 휴일, 03~06시 야간 3시간 + 06~09시 평시 3시간은 평일처럼 근무시간에 들어간다
- **그 달 근무시간** = 176 − 48 = **128시간** < 월 기준 160시간 → **기본 초과 0**
- **야간**: 야간 8번 × 8시간 = 64 − (10·18일 야간 중 휴일에 들어간 야간 5시간씩 10) = **54시간**
- **기본 초과 0 / 야간 54 / 휴일 48 (6일)**

## 사례 2. 사례 1 + 10/14(수) 야간일에 연가
