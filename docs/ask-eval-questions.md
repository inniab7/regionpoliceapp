# 규정 질문 정답표 (초안 — Yuni 검토 필요)

> PLAN 작업 32. **Claude가 쓴 초안**입니다. Yuni가 질문·정답 조문·정답 요지를 검토하고 고쳐 주세요. 고칠 곳은 `evals/questions.ts` 한 파일입니다(이 표는 그 내용을 옮긴 것).
> 통과 기준(PRD 성공 기준 5): AI마다 20문항 중 **18개 이상** 정답, 모든 답에 출처.

## 자동 채점 방법
- **일반 질문**: 등록 법령 안에서 답했고, 출처 중 하나가 아래 「정답 출처」에 있고, 「핵심 낱말」이 있으면 답에 모두 들어 있으면 정답
- **19번(등록 법령에 없음)**: 「등록된 자료에서 찾을 수 없습니다」로 답하면 정답 (지어내면 오답)
- **20번(현장 판단)**: 현장 판단 고정 문구가 붙고, 답을 했다면 출처가 정답 출처에 있으면 정답

## 검토할 때 봐 주세요
1. 질문이 현장에서 실제로 물어볼 만한 말투인지, 더 자주 묻는 질문이 있는지
2. 정답 출처(법령·조항)가 맞는지, 다른 조항도 정답으로 인정해야 하는지
3. 정답 요지의 법률 내용이 맞는지 (특히 7번 범칙금 금액, 12번 긴급체포 요건)
4. 질문을 바꾸거나 더하고 싶으면 알려 주세요. 20개를 유지하면서 바꿉니다.

## 시험 실행 방법
```bash
npm.cmd run eval
```
- `.env`에 있는 키로 AI별로 시험합니다: `OPENAI_API_KEY`(ChatGPT), `GEMINI_API_KEY`(Gemini), `ANTHROPIC_API_KEY`(Claude). 키가 없는 AI는 건너뜁니다.
- 결과는 `evals/results/{AI이름}.md`에 질문별 AI 답과 함께 저장됩니다(이 폴더는 git에 올라가지 않습니다).
