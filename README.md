# 현답

> 답이 있는 현장 근무자를 위하여

지구대·파출소·교대근무 경찰관을 위한 **스마트폰 웹앱**입니다. 앱 설치 없이 브라우저로 열어 쓰고, 홈 화면에 추가해 앱처럼 쓸 수 있습니다.

## 무엇을 하나요

스마트폰 브라우저에서 「홈 화면에 추가」하면 앱처럼 열리고, 열 때 시작 화면(경찰 마크)이 잠깐 보입니다.

### ① 초과근무 자동 산출
- 소속과 근무 패턴(5가지)을 한 번 등록하면 **한 달 근무표**가 달력으로 만들어집니다.
- 한 달의 **기본 초과 · 야간 · 휴일**(휴일은 8시간을 1일로 환산해 일수도 함께 표시)을 정해진 계산식으로 계산합니다. AI를 쓰지 않습니다.
- 휴가·교육·출장·추가 근무를 날짜를 눌러 바꾸면 결과가 바로 바뀝니다.
- 다른 팀의 팀 번호와 패턴 시작일을 등록하면(최대 6팀), 첫 화면에 「오늘 야간에 들어오는 팀」「내일 주간에 들어오는 팀」이 계속 보입니다.
- 시간만 계산하며 수당(금액)은 계산하지 않습니다. 결과는 참고용입니다.

### ② 규정 질의응답
- 형법, 경범죄 처벌법, 도로교통법, 도로교통법 시행령(별표 포함), 형사소송법, 경찰관 직무집행법, 개인정보 보호법 — **등록된 공개 법령 안에서만** 답합니다.
- 모든 답에 **출처(법령·조항)와 법령별 기준일**을 붙이고, 3문장(200자) 이내로 결론부터 답합니다.
- 등록된 자료에 없으면 추측하지 않고 「등록된 자료에서 찾을 수 없습니다」라고 답합니다.
- 「체포해도 되나요?」 같은 현장 판단 질문에는 조항만 안내하고 현장 판단은 하지 않습니다.
- 질문에 이름·주민등록번호·전화번호·차량번호가 있으면 AI로 보내기 전에 막습니다.

## 개인정보와 AI 키

- 등록 정보·근무 기록은 **사용자의 브라우저(기기) 안에만** 저장됩니다. 서버로 보내지 않습니다.
- 이름·연락처·계급·사번은 받지 않습니다. 로그인도 없습니다.
- AI는 **ChatGPT · Gemini · Claude 중 사용자가 골라 본인 API 키로 연결**합니다. 질문은 사용자 기기에서 그 AI 회사로 직접 가며, 이 앱의 서버를 거치지 않습니다. 제작자의 키는 들어 있지 않습니다.
- AI 키는 백업 파일에 들어가지 않고, [연결 끊기]를 누르면 기기에서 바로 지워집니다.
- 사용료는 고른 AI 회사가 키 주인에게 따로 청구합니다. (ChatGPT Plus 같은 구독과 API 키는 다릅니다.)

## 실행

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:3000)
```

```bash
npm run lint       # 코드 검사
npm run test       # 계산·검색·검사 시험 (AI를 부르지 않음)
npm run build      # 배포용 빌드
```

### 법령 최신본으로 갱신
```bash
npm run laws       # 국가법령정보센터 공개 API에서 7종을 받아 public/laws/ 갱신
```
법령이 개정되면 실행하세요. `index.json`의 기준일·버전이 바뀌어, 사용자 기기가 바뀐 법령만 다시 받습니다.

### 규정 정답률 시험 (실제 AI 호출)
```bash
npm run eval
```
`.env`에 `OPENAI_API_KEY`, `GEMINI_API_KEY`, `ANTHROPIC_API_KEY`가 있는 AI만 시험합니다. 이 키들은 시험 스크립트에서만 읽으며, 앱 코드는 `.env`를 읽지 않습니다.

```
lib/privacy/    개인정보 감지
public/laws/    법령 7종 JSON + index.json
evals/          규정 정답률 시험
```

## 안내

- 이 앱은 경찰청·소속 관서의 공식 시스템이 아니며, 내부망 시스템과 연동하지 않습니다.
- 초과근무 계산은 **참고용**이며, 최종 확정은 소속 관서 집계 기준을 따릅니다.
- 규정 답변은 AI가 등록된 법령 조문을 요약한 것으로, 법률 조항 안내일 뿐 현장 판단이 아닙니다. 내부 지침이나 상급자의 지시를 따르세요.
- 법령 데이터 출처: 국가법령정보센터 (공개본)
